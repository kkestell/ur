# ur

ur is a desktop and command-line client for ACP agents. It keeps sessions and terminals available
across GUI restarts.

## Keyboard shortcuts

| Action            | macOS                  | Other platforms  |
| ----------------- | ---------------------- | ---------------- |
| New Session       | Command+N              | Meta+N           |
| New Terminal      | Command+Shift+N        | Meta+Shift+N     |
| Close Tab         | Command+W              | Ctrl+W           |
| Reopen Closed Tab | Command+Shift+T        | Ctrl+Shift+T     |
| Allow once        | Command+Y              | Meta+Y           |
| Always allow      | Command+Shift+Y        | Meta+Shift+Y     |
| Reject once       | Command+Option+Z       | Meta+Alt+Z       |
| Always reject     | Command+Shift+Option+Z | Meta+Shift+Alt+Z |

Permission shortcuts answer the active session's oldest pending request when it has the matching
option.
