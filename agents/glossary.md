# Glossary

## Naming

- Agent means a coding agent program run in a pane, such as Claude Code, Codex, OpenCode, or ox-tui.
- Qualify tmux session, tmux server, and tmux client.
- Use pane for a tmux pane.

## Terms

- **ur**: The tmux configuration, with its install scripts and agent hooks.
- **ox-tui**: A separate interactive terminal ACP client. ur marks its panes from its terminal
  title.
